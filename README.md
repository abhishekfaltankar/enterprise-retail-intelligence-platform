# 🛒 Enterprise Retail Intelligence Platform

An end-to-end AI-powered retail analytics platform built using Python, SQL, PostgreSQL, Power BI, Machine Learning, FastAPI, and Streamlit.

## 🚀 Project Goals

- Analyze retail sales data
- Build SQL analytics
- Create interactive Power BI dashboards
- Forecast future sales
- Predict customer churn
- Segment customers
- Recommend products
- Build an AI-powered business assistant

## 🛠️ Tech Stack

- Python
- PostgreSQL
- SQL
- Pandas
- NumPy
- Scikit-learn
- Plotly
- Power BI
- FastAPI
- Streamlit
- Git & GitHub
